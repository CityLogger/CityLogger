# CityLog logo templates

These four SVGs have transparent backgrounds and can be saved, resized, or
edited in any vector editor. The primary version follows the original app logo:
a slightly tilted green rounded square, white map-pin outline, and dark lowercase
`citylog` wordmark. The app's opening, onboarding, map, and sign-in views use
this same original mark.

| Version | File |
| --- | --- |
| Green rounded-square badge + citylog | `public/branding/citylog-bubble-wordmark.svg` |
| Green rounded-square badge only | `public/branding/citylog-bubble-mark.svg` |
| Green outline + citylog | `public/branding/citylog-outline-wordmark.svg` |
| Green outline only | `public/branding/citylog-outline-mark.svg` |

Primary brand green: `#2F7656`. Wordmark ink: `#213D32`. The lettering is
editable SVG text using Manrope with a system fallback; install Manrope before
exporting in a design tool for the closest match to the app.

These are transparent brand assets, not replacements for the opaque iOS app icon.
